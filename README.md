# Распознавание дорожных знаков (Traffic Sign Recognition)

Проект по классификации дорожных знаков с использованием свёрточной нейронной сети (CNN). Модель обучена на наборе данных German Traffic Sign Recognition Benchmark (GTSRB) и способна распознавать более 40 типов знаков (ограничения скорости, приоритет, запрещающие и т.д.). 

В репозитории есть всё необходимое для запуска: обученная модель (`traffic_sign_model.keras`), скрипты для проверки на изображениях и видео, а также тестовые и пользовательские фотографии.

## Структура проекта
.
├── traffic_sign_recognition_MAIN.py # Главный скрипт: обучение или оценка модели
├── traffic_sign_recognition_APP.py # Приложение для распознавания на изображениях/видео
├── traffic_sign_recognition_CHECK.py # Скрипт для проверки на тестовых данных
├── traffic_sign_recognition_CHECK_TEST.py # Дополнительные тесты
├── traffic_sign_model.keras # Готовая обученная модель Keras
├── labels.csv # Соответствие классов дорожным знакам
├── requirements # Файл с зависимостями
├── myData/ # Данные для обучения/валидации
├── TESTS/ # Тестовые изображения
├── CUSTOM PHOTOS/ # Ваши собственные фото знаков
├── docs/ # Документация
└── apidocs/ # API-документация
